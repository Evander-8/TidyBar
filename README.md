# TidyBar

极简、低内存、零第三方依赖的 macOS 原生菜单栏图标管理工具（macOS 14.0+）。

## 核心特性

- **常驻极轻量**：纯 AppKit 驱动（`LSUIElement = true`），空闲态 0% CPU、零后台轮询；二级下拉栏关闭即释放图像缓存，偏好设置窗关闭即销毁 SwiftUI 视图树。
- **三段式分区**：支持 `[总是隐藏区] ‖ [隐藏区] | [TidyBar] [常显区]`，日常只看「隐藏区」，`Option + 点击` 展开全部。
- **双展示模式**：
  - **二级下拉栏模式（默认）**：点击主图标在菜单栏下方弹出毛玻璃面板，避免 MacBook 刘海屏图标溢出。
  - **原地展开模式**：零系统权限、直接收缩空白展开顶部菜单栏图标。
- **防自锁安全守卫**：折叠前自动校验分割线与主开关几何顺序，杜绝分割线被误拖到主开关右侧导致自身被隐藏。
- **顺手细节**：展开后自动定时收起（支持鼠标悬停保活）、点击外部或切换应用自动收起、全局快捷键自定义、开机自启（`SMAppService`）、4 种主开关与 3 种分割线样式。

## 使用方法

1. 启动 TidyBar 后，首次会自动打开**「图标管理」**设置窗口（也可随时右键点击菜单栏主图标选择**「管理隐藏图标…」**）。
2. **可视化选择要隐藏的图标**：在「图标管理」页的「常显图标」列表中点击 **「隐藏」** 或 **「总是隐藏」**，TidyBar 会自动把图标移入对应分组并立即在菜单栏隐藏（需要授权辅助功能权限）。
3. **快速切换查看**：
   - **左键点击主开关**（或按 `⌃⌥H`）：查看/收起「隐藏区」图标
   - **按住 `⌥ Option` + 点击主开关**：一并展示「总是隐藏区」
   - **右键主开关**：随时切换二级下拉栏 / 原地展开模式、调整自动收起时长、校准分割线位置或打开偏好设置
4. 也支持传统手动分组：按住 `⌘` 键手工将图标拖到 `|` 或 `‖` 左侧。

## 系统权限说明

- **原地展开模式**：完全不需要任何系统权限。
- **二级下拉栏模式与可视化图标管理**：
  - 仅需 **辅助功能权限**：用于在「图标管理」页自动分组移动图标，以及在点击二级下拉栏图标时向真实状态栏图标转发左/右键点击。**全程不请求屏幕录制权限**，绝不触发 macOS 15 录屏确认弹窗。
